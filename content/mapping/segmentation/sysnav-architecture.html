SysNav — Complete System Architecture

TLDR: SysNav is a three-level object navigation system that decouples semantic reasoning (VLM), navigation planning, and motion control to enable reliable, building-scale object search across wheeled robots, quadrupeds, and humanoids. It restricts VLM reasoning to room-level decisions and uses classical exploration within rooms, achieving 4-5× efficiency gains over baselines in 190 real-world experiments. Haokun Zhu, Zongtai Li, Zihan Liu, Kevin Guo, Zhengzhi Lin, Yuxin Cai, Guofei Chen, Chen Lv, Wenshan Wang, Jean Oh, Ji Zhang. Carnegie Mellon University, NYU, NTU. March 2026.
