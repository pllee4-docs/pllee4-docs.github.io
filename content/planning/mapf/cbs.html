Conflict-Based Search (CBS)

TLDR: CBS solves multi-agent pathfinding optimally by splitting the problem into two levels — a high-level Constraint Tree that resolves inter-agent conflicts by branching, and a low-level A* that replans individual agents under constraints. This avoids the exponential joint state space of traditional A* while guaranteeing optimal sum-of-costs solutions. MA-CBS extends this by adaptively merging strongly-coupled agents into meta-agents to handle pathological open-space cases. G. Sharon, R. Stern, A. Felner, N.R. Sturtevant. "Conflict-based search for optimal multi-agent pathfinding." Artificial Intelligence, 219, pp. 40–66, 2015. doi:10.1016/j.artint.2014.11.006

Input

Constraint: No two agents may occupy the same vertex at the same time.
Objective: Minimize the sum of costs — the total path lengths of all agents.

Node D is a bottleneck — both agents must pass through it. Their individual shortest paths both traverse D at timestep 2.

3. CBS: Two-Level Architecture

CBS splits the problem into two levels:

High level — searches a Constraint Tree (CT), a binary tree where each node holds a set of constraints and a solution (set of paths). Best-first search on the CT orders nodes by their total cost. When a conflict is found, the node splits into two children, each adding one new constraint.

Low level — for each CT node, runs A* to find the shortest path for an individual agent that satisfies all its constraints. The search space is (vertex, time) pairs — a state (v, t) is pruned if the constraint (aᵢ, v, t) exists.

6. Multi-Valued Decision Diagram (MDD)

An MDD compactly stores all optimal-cost paths for a single agent from start to goal. Each level of the MDD corresponds to a timestep, and each node is a vertex the agent can occupy at that time while still reaching the goal optimally.

Why MDDs matter for CBS: An MDD for agent aᵢ with cost cᵢ is the set of all vertices reachable at each timestep along some optimal path. CBS uses MDDs to classify conflicts:

Cardinal conflict: Both agents' MDDs have width 1 at the conflicting timestep — resolving the conflict must increase the cost of at least one agent. CBS should prioritize these conflicts.

Semi-cardinal: Only one MDD has width 1 — the cost of one agent must increase.

Non-cardinal: Both MDDs have width > 1 — the agents may reroute without cost increase.

Construction: An MDD is built in two passes over a levels_ vector:
1. Forward pass — BFS from Start, keeping only vertices where t + h(v) ≤ optimal_cost.
2. Backward pass — from Goal back to Start, pruning any vertex that cannot reach a surviving vertex in the next level. This removes dead ends caused by constraints that block future timesteps.

Why Backward?
Backward Pass
The forward pass is greedy — it can't see the future.

At each timestep t, it adds every cell that is:
  1. Reachable from some cell in levels_[t]
  2. Close enough to Goal: t+1 + h(cell) ≤ optimal_cost
  3. Not blocked by a vertex or edge constraint at t+1
But it never checks whether a cell at t+1 can actually reach Goal through levels_[t+2], levels_[t+3], ... — constraints at future timesteps might block every onward path.

Example: Cell (3,1) at t=4 passes all forward checks — it's reachable from (3,0) at t=3, and 4 + h(3,1) = 4+2 = 6 = optimal_cost ✓. Its only h-feasible successor is (3,2) at t=5. But (3,2) is blocked at t=5 by another agent's constraint. So (3,1) at t=4 is a dead end — reachable from Start, but unable to reach Goal.

The backward pass catches this: starting from Goal and working back, it keeps only cells that can reach a survivor at the next level. Dead ends are pruned, and the pruning cascades: (3,1) is pruned, which makes (3,0) at t=3 a dead end too (its only successor was (3,1)). Meanwhile, paths through (2,3) at t=5 survive.

8. Meta-Agent CBS (MA-CBS)

Adaptive Merging

When a pair of agents conflicts more than B times, MA-CBS merges them into a meta-agent — solved by a joint MAPF solver at the low level instead of individual A* searches.

B = ∞ is basic CBS (never merge).
B = 0 always merges on first conflict, equivalent to the Independence Detection (ID) framework.
0 < B < ∞ adapts: loosely-coupled agents stay separate (CBS advantage), strongly-coupled agents merge (joint-solver advantage).

Experiments show MA-CBS with intermediate B values outperforms both basic CBS and pure joint A* across most map topologies.

9. Properties

Optimality. CBS performs best-first search on the CT ordered by total cost. Since each CT node's cost is a lower bound on all solutions it permits (Lemma 1), the first goal node found is optimal (Theorem 1).

Completeness. For any cost C, there are finitely many CT nodes with cost ≤ C (Theorem 2). CBS systematically explores them, so it will find a solution if one exists (Theorem 3). It will not detect unsolvable instances on its own — a separate solvability check is needed.

Implementation notes. Each CT node stores only its delta — the new constraint and replanned path. The full constraint set and solution are reconstructed by walking to the root. This keeps CT nodes cheap and lets the tree grow large. Duplicate detection and tie-breaking by conflict count (conflict avoidance table) provide additional speedups.
